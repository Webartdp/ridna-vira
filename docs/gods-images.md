# Нові портрети й швидке завантаження розділу «Боги»

Перемальовано вісім образів: Дажбог, Коляда, Лада, Мокош, Перун, Род, Святовит, Ярило. Оригінали нових зображень закомічені як `public/assets/gods/{slug}/portrait.png`. Це окремо згенеровані зображення, а не збільшені старі мініатюри.

Для всіх 42 образів підготовлено WebP з повнорозмірних PNG:

- `card-320.webp` — 320 × 400, для невеликих карток;
- `card-640.webp` — 640 × 800, для більших карток та екранів із високою щільністю пікселів;
- `portrait.webp` — 960 × 1200, для окремої сторінки та найщільніших екранів.

Шаблони використовують спільний partial із srcset/sizes та заданими width/height. Перші чотири картки завантажуються одразу, решта — native lazy loading із низьким пріоритетом. На окремій сторінці портрет має високий пріоритет. Версія файла в URL оновлюється при зміні зображення.

У розділі прибрано завантаження старої фонової текстури 15 МБ; замість неї використано той самий світлий базовий колір. Окремо прибрано непотрібний запит Google Fonts: фірмові шрифти вже лежать локально.

## Вага зображень

Попередній вибір portrait.webp/portrait.png для всіх 42 карток важив **97 663 593 байти**. Тепер усі версії 320px разом важать **1 755 314 байтів**, 640px — **6 386 138 байтів**. Це зменшення сукупного обсягу портретів приблизно у 55,6 або 15,3 раза відповідно; фактичний вибір визначає браузер за розміром картки та екраном. Нижні картки завантажуються при наближенні до видимої області.

PNG-оригінали залишаються в репозиторії для повторної підготовки, але картки їх не завантажують.

## Повторна підготовка

Потрібна лише при зміні оригіналів:

```bash
python -m pip install Pillow
python scripts/prepare-god-images.py
```

Всі 126 WebP закомічені, на сервері не потрібні Python чи ImageMagick.

## Деплой

```bash
sudo -u ridnavira-com-ua -H /bin/bash <<'DEPLOY'
set -euo pipefail
cd /home/ridnavira-com-ua/web/ridnavira.com.ua/public_html/app
git switch feature/site-build
git pull --ff-only origin feature/site-build
npm run build
php artisan optimize:clear
php artisan view:cache
git rev-parse HEAD
DEPLOY
```

Production-збірка потрібна через видалення зовнішнього підключення шрифтів. Імпорт контенту, Composer update та міграції не потрібні.

## Перевірки

- 10 наявних тестів / 53 assertions, компіляція Blade та production-збірка.
- Всі 126 WebP декодуються, розміри та співвідношення сторін перевірені.
- Каталог із 42 зображеннями та окрема сторінка на ширинах 320, 390, 768, 1440px; DPR 1 і 2.
- Перевірено вибір WebP через srcset, eager/lazy атрибути, відсутність PNG у картках, відсутність запиту texture.png, горизонтального переповнення та JavaScript-помилок.
