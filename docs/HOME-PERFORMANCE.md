# Зображення головної та календар адмінки

## Зміни

- Замість завантаження вихідних іконок 1254×1254 для маленьких карток браузер вибирає розмір через `srcset` / `sizes`.
- Фонова текстура: оригінал 4096×2731, 15 496 640 байтів. Для CSS-розміру 622px створені варіанти 622/1244/1866px для екранів 1×/2×/3×. Профіль ICC збережено.
- Оригінали залишаються в `public/assets/figma/home`. Варіанти у `public/assets/optimized-home` закодовано WebP lossless, з перевіркою тотожності декодованих пікселів кожному підготовленому зображенню. Адаптивне зменшення розмірів використовує Lanczos; це окрема операція від стиснення. Повнорозмірні оригінали не змінено.
- Якщо точний WebP не менший за оригінал, використовується оригінал. Наприклад, головний hero залишається 311-КБ вихідним файлом.
- Нижні іконки, колесо й декорації отримали lazy loading, async decoding та явні розміри. Логотип, кошик і декор першого екрана завантажуються одразу.
- Hero отримав preload / high priority. Якщо в CMS встановлено власний hero, підвантажується саме він.
- Обробка виконується після CMS-підстановок: старі збережені головні теж отримують оптимізовані зображення. Зовнішні картинки, YouTube-прев’ю та користувацькі завантаження не переписуються.
- В адмінці календаря нативний список місяців замінено компонентом Filament з пошуком і належними кольорами темної/світлої тем. Вибір місяця та збереження свят перевірено.

## Перевірка

124 тести, 4017 тверджень — успішно. `npm run build`, `view:cache`, `route:cache` — успішно.

Локальний браузер Chrome, 1440×1000, DPR 1, без кешу. Для порівняння того самого набору зображень до оптимізації браузеру віддавалися вихідні файли. При повному прокручуванні сторінки в обох випадках завантажено 44 унікальні зображення:

| Показник | Оригінали | Оптимізована версія |
|---|---:|---:|
| Зображення початкового завантаження | 54 574 688 байтів | 1 377 811 байтів |
| Зображення повністю прокрученої головної | 54 816 396 байтів | 2 879 109 байтів |

Скорочення повного обсягу зображень — близько 94,7%. Це локальний замір ваги зображень, а не вимір часу завантаження production-сервера. На екранах з іншою щільністю пікселів браузер вибере інші розміри.

Регенерація за потреби: встановлений Python із Pillow, команда `python tools/optimize-home-images.py` у корені репозиторію. Для деплою Python не потрібен: готові файли та JSON-маніфест включені в Git.

## Деплой

Команди також застосовують попередню міграцію громад, якщо вона ще не виконувалася.

```bash
sudo -u ridnavira-com-ua -H /bin/bash -c '
set -e
cd /home/ridnavira-com-ua/web/ridnavira.com.ua/public_html/app
php artisan down
trap "php artisan up" EXIT
git pull --ff-only origin feature/site-build
php artisan migrate --force
npm ci --no-audit --no-fund
npm run build
php artisan optimize:clear
php artisan filament:assets
php artisan filament:optimize-clear
php artisan view:cache
php artisan route:cache
'
```

## Соцмережі та заглушка (попередній коміт)

У **Сайт → Налаштування сайту й оплати → Соціальні мережі** задаються HTTPS-посилання Facebook, Instagram, Telegram, YouTube, TikTok. Порожні поля приховують відповідні іконки. Посилання використовуються також у `Organization.sameAs`. Редагувати може лише адміністратор; ключ WayForPay, як і раніше, не повертається у форму.

Заглушка `public/assets/brand/image-placeholder.svg` (3708 байтів) використовує наявний знак `logo-sva.svg`, графітове тло та золоті акценти. Вона підставляється в порожні слоти фото матеріалів, громад, товарів і святинь; реальні зображення та YouTube-прев’ю збережено.
