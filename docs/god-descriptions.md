# Описи Богів

Усі 42 записи каталогу мають окремі редакційні описи українською в `resources/content/gods.json`. Кожен запис містить короткий опис для картки, вступ, тематичні розділи й прямі посилання на використані матеріали.

Джерела опрацьовано 9 листопада 2026 року:

- [Світовит Пашник: Боги](https://svit.in.ua/bog.htm), окремі статті та авторські видання, на які посилається розділ.
- [Громада «Полум’я Роду»: Рідні Боги](https://yaro.dp.ua/rid.html) та окремі матеріали розділу.
- [Об’єднання рідновірів України: Рідні Боги](https://www.oru.org.ua/index.php/bogoznavstvo/ridni-bogi.html) та окремі статті.

Тексти написано заново, без перенесення оформлення джерел. Відмінні тлумачення та сучасні авторські реконструкції позначено безпосередньо в описах. Зокрема, уточнено образ Горині як плакальниці, народний образ Мамая та порівняльне походження запису про Яму. Для Хорса наведено відмінність сонячного й місячного тлумачень.

`App\Support\GodDescriptions` надає ці дані контролеру та скрипту імпорту. На сторінках відомих Богів новий текст має перевагу над раніше імпортованим HTML. Архівні файли не змінюються; додаткові записи імпорту без нового опису зберігають попередній спосіб відображення.

## Оновлення сервера

Достатньо отримати зміни гілки та оновити кеш Laravel. Повторний імпорт, завантаження матеріалів із джерел і збірка npm для цієї зміни не потрібні. Під час перегляду сторінок зовнішні джерела не завантажуються.

```bash
git pull --ff-only origin feature/site-build
php artisan optimize:clear
php artisan view:cache
```

## Перевірки

`tests/Feature/GodDescriptionTest.php` перевіряє відповідність усіх 42 записів каталогу, відкриття сторінок, показ джерел, перевагу нових описів над імпортом і роботу додаткового архівного запису.
