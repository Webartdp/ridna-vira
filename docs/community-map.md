# Карта громад на сторінці зв’язку

9 листопада 2026 року на живому сайті підтверджено проблему: CARTO замість географічної підкладки повертав зображення `API KEY REQUIRED`. Leaflet та позначки працювали, помилок JavaScript не було.

Джерело підкладки замінено на стандартні тайли OpenStreetMap. Налаштування URL, атрибуції та граничного масштабу винесено в `config/community_map.php` і передається до JavaScript через атрибути контейнера карти. Подальшу заміну провайдера можна зробити в конфігурації.

Збережено 19 позначок із 22 громадами та представництвами, пошук, фільтри й контактні вікна. Дані громад та контактну форму не змінено.

Використовується офіційний HTTPS endpoint `https://tile.openstreetmap.org/{z}/{x}/{y}.png` з видимим посиланням на авторство. Кешування виконує браузер за заголовками сервера; офлайн-завантаження або попереднє завантаження територій не застосовуються. Умови сервісу: https://operations.osmfoundation.org/policies/tiles/.

Перевірено реальне відображення підкладки в браузері, пошук Запоріжжя, фільтрацію Західного Кола за представництвами, відкриття контактів Києва та ширини екрана 320, 390, 768 і 1440 px. Повторні перевірки взаємодії використовували тестові зображення без додаткового завантаження тайлів сервісу. Збірка npm та всі 25 тестів (1954 перевірки) пройшли.

## Деплой

Ця зміна потребує оновлення зібраного JavaScript:

```bash
git pull --ff-only origin feature/site-build
npm run build
php artisan optimize:clear
php artisan view:cache
```

Нових пакетів npm або Composer не додано.
