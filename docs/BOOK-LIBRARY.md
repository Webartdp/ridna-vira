# Книги в адмінці

Причина розбіжності: `/ridna-vira/knyhy` читала `config/faith_books.php`, а `/admin/books` показувала тільки таблицю CMS. Посилання на статичні файли не імпортували окремих записів книг.

Міграція `2026_11_10_000005_import_book_library` додає JSON-метадані книги до `content_pages` і створює 23 записи з конфігурації. Наявні записи, включно з видаленими, не перезаписуються. Початкові локальні файли не переміщуються й не завантажуються повторно.

Публічна бібліотека тепер використовує `BookLibrary`: зміни назви, опису, категорії, автора, року, обкладинки й файлів беруться з CMS. Чернетки, заплановані й видалені книги приховані. Після збереження правки діють також на старий CMS-макет списку завдяки динамічним блокам каталогу та лічильників. Інші тексти сторінки зберігаються.

В адмінці **Рідна Віра → Книги → Змінити**:

- **Матеріал**: назва, короткий опис, обкладинка, розгорнутий текст.
- **Видання та файли**: автор, видавництво, рік, сторінки, заміна PDF/DOCX та перемикач доступності кожного формату.
- **Публікація**: видимість, дата, категорія.
- **SEO**: метадані.

Порожнє поле заміни PDF/DOCX залишає початковий локальний файл імпортованої книги. Перемикач формату приховує його зі сторінки та вимикає маршрут завантаження. Завантажені заміни зберігаються в публічному диску в `books/`; маршрути не дозволяють завантажувати довільні файли з інших каталогів. Старі статичні публічні URL залишаються доступними як раніше.

Імпорт також викликається командою `site:import`. Повторний імпорт не скидає правки. На rollback записи та колонка зберігаються, щоб не втратити редакторські дані.

Перевірка: 127 тестів, 4041 твердження; кешування Blade і маршрутів успішне. Локально перевірено відображення 23 книг та редагування через Filament.

## Оновлення сервера

```bash
sudo -u ridnavira-com-ua -H /bin/bash -c '
set -e
cd /home/ridnavira-com-ua/web/ridnavira.com.ua/public_html/app
php artisan down
trap "php artisan up" EXIT
git pull --ff-only origin feature/site-build
php artisan migrate --force
php artisan optimize:clear
php artisan filament:optimize-clear
php artisan view:cache
php artisan route:cache
'
```

Нові JS/CSS-збірки чи залежності для цього виправлення не додаються.
