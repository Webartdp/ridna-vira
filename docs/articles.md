# Виправлення сторінок статей

Причина однакових назв «Ridna Vira»: імпортер не відрізняв загальні h1/title старого сайту від заголовка статті. Назва посилання у вихідному списку зберігалася в `source_label`, але не використовувалась для показу. Старі файли також містили таблиці для верстки, font, фонові кольори та друковані розриви сторінок.

Тепер список показує назву, уривок і посилання на читання, по 18 матеріалів на сторінку. Прибрано позначки HTML, розміри файлів і службову інформацію про імпорт. Окрема стаття має власний заголовок, читабельну ширину рядка, абзаци, підзаголовки й адаптивне оформлення.

`ArticleContent` відділяє текст від оформлення старої сторінки, зберігає зміст, списки, виділення, посилання та таблиці даних. Довгі прозові частини, розділені br, стають абзацами; короткі віршовані рядки зберігають переноси. Послідовні друковані номери сторінок видаляються; розірвані ними речення з’єднуються. Небезпечні теги, обробники подій і javascript-посилання не потрапляють у вивід.

Наявні імпортовані файли й manifest не перезаписуються: виправлення застосовується під час показу, з кешуванням результату. Адреси статей та завантаження залишаються чинними. Оновлений імпортер використовує той самий нормалізатор і повторно використовує slug за source_url, щоб наступний імпорт не змінював існуючі адреси.

Фірмові шрифти взято з наданих власником `Holos-bold.zip` і `KyivRegion-Regular.zip`: вони потрібні на вже оголошених у CSS адресах `/fonts/…`. Оформлення головної, header та footer не змінюється.

## Деплой

```bash
sudo -u ridnavira-com-ua -H /bin/bash <<'DEPLOY'
set -euo pipefail
cd /home/ridnavira-com-ua/web/ridnavira.com.ua/public_html/app
git switch feature/site-build
git pull --ff-only origin feature/site-build
npm ci --include=dev
npm run build
php artisan optimize:clear
php artisan view:cache
git rev-parse HEAD
DEPLOY
```

Повторний імпорт, міграції та видалення `storage/app/content/articles` не потрібні. Для Vite потрібен Node.js 20.19+ або 22.12+.

## Перевірки

10 тестів, 53 assertions: виправлення загальних назв, незмінність існуючих URL і оригінальних файлів, читання та завантаження, пагінація, таблиці даних, абзаци й вірші, друкована пагінація, небезпечна розмітка. Production-збірка, Blade cache та PHP style check проходять. Додатково перевірено реальні проблемні матеріали на ширинах 320, 390, 768 і 1440px.
