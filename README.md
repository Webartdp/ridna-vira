# Рідна Віра

Офіційний сайт Духовного центру «Рідна Віра» для домену `ridnavira.com.ua`.

## Технології

- Laravel
- Blade
- Bootstrap 5
- SCSS
- Vite
- MySQL / MariaDB

## Основні розділи

- Головна
- Про центр
- Рідна Віра
- Новини
- Статті
- Творчість
- Крамничка
- Кошик і оформлення замовлення
- Зв’язок

## Етапи розробки

1. Базова структура Laravel та дизайн-система.
2. Адаптивна верстка сторінок за PDF-макетами.
3. Моделі, міграції, адмінпанель і керування контентом.
4. Каталог, кошик, замовлення та інтеграція Нової Пошти.
5. SEO, оптимізація, тестування та розгортання на `ridnavira.com.ua`.
